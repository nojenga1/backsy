Installing the unpacked build

While Backsy is in review, you can load it yourself in under a minute:

  1. Start the Backsy app so the extension has something to talk to.
  2. Open chrome://extensions.
  3. Turn on Developer mode, top right.
  4. Click Load unpacked and pick the ext folder.

The Backsy icon appears in your toolbar. Click it to send, cancel, and claim.

The store links above are placeholders. Publishing to the Chrome Web Store needs a developer account and a hosted backend — until then, the unpacked build is the way in.

Works on any Chromium browser. Need a hand? See Support.

Backsy is an early prototype. Reversible transfers are demonstrated with a simulated escrow — no on-chain program is deployed and no real funds move.
